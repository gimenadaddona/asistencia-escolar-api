\# Sistema de Asistencia Escolar



Proyecto integrador — API para el control de asistencia diaria,

nómina por ciclo/año/división, alertas de inasistencia y seguimiento de

acciones entre docentes, equipo directivo y equipo de orientación.



\## Arquitectura



Clean Architecture (4 capas) + Screaming DDD, con FastAPI como framework

de entrega.
